# Rubric — scoring an advisory run (0 / 1 / 2 per criterion)

The same three-point pattern for every row:

- **0 — missed or wrong.** The issue never surfaced, or the advice
  contradicts the playbook/thesis (e.g. pitches investing to Dre while the
  26.99% card lives; prices Nimbus at secondary chatter).
- **1 — named, not actionable.** The issue is mentioned but missing its
  dollar figure, OR missing the surface (which login/site/phone call), OR
  hedged into mush ("you might want to look into your withholding").
- **2 — flagged with $ and surface.** Right order-of-magnitude dollar
  figure AND a concrete next move on a named surface, consistent with the
  household's THESIS. (report.md rule: "every move carries its dollar
  figure and the surface it happens on".)

Score every row for the persona under test, then the craft rows. A run
passes at **≥ 80% of available points with no 0 on a MUST row**.

## Scoring notes
- Dollar figures score on order of magnitude, not cents; a figure the data
  contradicts scores 0 even if the theme is right.
- "Surface" = where the move happens: a login, an issuer phone line, a
  form (W-4/ES), a settings page. "Talk to a professional" alone is a 1.
- If a MUST row was impossible because the run never loaded facts/ or the
  ledger, score what happened, but note the process failure — that is a
  skill bug, not a persona bug.
