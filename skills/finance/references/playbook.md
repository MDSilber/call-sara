# The advisory playbook — how to see between the lines

Distilled from the CFP Board domain map, fpPathfinder's checklist library
(Kitces), the pre-IPO / concentrated-equity literature, state estate-tax law,
and behavioral-finance practice. **State-specific rules are marked [state:XX]
— apply the ones matching the household profile's state; skip the rest.** Consult on every **review**, and whenever a
new fact enters the vault. The rules below are TRIGGERS: walk the data
against them; anything that fires becomes a finding with a dollar figure.

Precision beats coverage. A rule that fires wrong costs trust. When
unsure, say what would confirm it and go check.

Two rules earned the hard way, before any of the below:
- **Load the complete picture before prescribing** (statements, paystubs,
  plan docs, the return). A generic high-earner playbook misfires on a
  client who's already built better systems than it prescribes.
- **Price every recommendation against the client's actual holdings**
  before stating a dollar value. "~$5K/yr" that turns out to be a wash at
  today's yields is worse than saying nothing.

## Part 1 — Pattern-spotting rules (IF in the data → FLAG)

### Cash & flows
- IF cash > cushion + 12mo known outlays with no earmark → idle-drag; put a
  number on the annual cost. (But see Part 5: for a vigilant client a fat buffer
  can be a legitimate purchase of sleep — flag, don't nag.)
- IF cash > $250K per institution/ownership category → FDIC concentration;
  ladder or hold Treasuries/govt MMF. Post-liquidity this fires immediately.
- IF a known outlay < 5 years out (taxes on a vest, a purchase) → that
  dollar does not belong in equities.
- IF gross income − taxes − savings ≠ stated spending → back-solve real
  spending from the return; never trust a self-reported number.
- IF bills are smooth but income is lumpy → the tension is a PLUMBING
  problem, not a spending problem; fix account depth/routing.
- IF a large lump-sum outflow recurs (school Zelle batches, quarterly IRS)
  → never average it into a fake monthly; model it as a lump.

### Tax — the cliff map (check projected AGI/MAGI against every line yearly)
- IF MAGI > $250K MFJ → 3.8% NIIT on all investment income (permanently
  true here) → shifts muni-vs-taxable and asset-location math.
- IF wages > $250K MFJ → 0.9% Additional Medicare; each employer only
  withholds vs. its own wages, so MFJ couples routinely under-withhold.
- IF supplemental income (RSU/bonus) withheld at flat 22% but marginal is
  32–37% → gap = (marginal − 22%) × supplemental income; make estimates or
  raise W-4. The most predictable April surprise for equity-comp households.
- IF prior-year tax covered < 90% by withholding+estimates → underpayment
  penalty; safe harbor = 100% of prior-year tax (110% if AGI > $150K).
  Extra December withholding is treated as paid ratably all year — the
  cleanest cure.
- IF AMT was assessed → find the trigger (ISO exercise is #1); model the
  crossover before any future exercise.
- IF ISOs held → model AMT crossover yearly; AND note the special year:
  the year double-trigger RSUs settle, the ordinary income creates
  massive AMT room — often enough to exercise ALL ISOs AMT-free.
- IF cap-loss carryforward exists → sequence future gains to consume it;
  BUT losses offset capital gains, NOT RSU/NQ ordinary income (only $3K/yr
  of that). RSU basis = FMV at settlement → immediate sale ≈ $0 gain.
- IF charitable but hovering near the standard deduction → bunch years
  into one via DAF; fund with the LOWEST-basis long-term lots (never cash).
- IF non-itemizer (2026+) → $2,000 above-the-line CASH gift deduction
  (direct to charity, NOT to a DAF) in the off years.
- IF Schedule B interest/dividends don't reconcile to known accounts →
  a held-away or forgotten asset; investigate.
- IF short-term gains disproportionate on Sched D → holding-period leak.
- IF bond fund or MMF sits in TAXABLE at a top bracket → most expensive
  holding per dollar; relocate bonds to tax-advantaged or swap to munis.
- [state:NY] IF a Treasury MMF is held → verify the fund's US-govt-
  obligation % each January (NY denies the state exemption below 50%).
  (Most states with an income tax have an analogous rule — check yours.)
- IF SALT-limited (AGI over the OBBBA phase-down) → assume the $10K floor;
  no itemizing without bunching.

### Retirement accounts
- IF backdoor Roth + ANY pre-tax IRA balance → pro-rata trap; roll pre-tax
  IRA into the 401(k) first, keep trad/SEP/SIMPLE IRAs at $0 on Dec 31.
- IF plan allows after-tax + in-plan conversion → mega-backdoor Roth is
  the largest tax-free lever for a high W-2 (only if cash flow tolerates —
  see the paycheck reality of the specific client).
- IF over the direct-Roth income limit but contributing directly →
  excess-contribution error.
- IF ESPP with discount/lookback exists and unused → guaranteed return
  left on the table.

### Concentration & liquidity events
- IF any position > 10–15% of net worth → concentration; but IF it is
  ALSO the employer → three-layer exposure (vested + unvested + human
  capital / salary) — treat the household as MORE concentrated than the
  balance sheet shows.
- IF concentrated → run the drawdown test: goals if the stock falls 50%
  and stays there 24 months. The right way to answer "how much is too
  much" for an anxious client.
- IF insider / will hold MNPI post-IPO → establish a 10b5-1 plan in an
  open window BEFORE lockup expiry (also assume the employer may mandate
  it). Doubles as the pre-commitment device.
- IF a huge one-year gain looms → toolkit: staged sales across tax years,
  appreciated-share gifting to DAF, exchange funds, direct-indexing losses.
  Hedging (collars/PVFs) is usually BANNED by employee trading policies —
  verify, don't plan on it.
- IF pre-IPO with vested options → the PERISHABLE window: only EXERCISED
  SHARES can be transferred pre-IPO (RSUs and options themselves cannot).
  Estate freeze at the 409A/appraised value must complete before pricing;
  appraisal + company approval + drafting = 60–90 days, and many companies
  freeze cap-table transfers late in the process.
- IF double-trigger RSUs will settle → get in writing: settlement date,
  sell-to-cover mechanics, withholding-rate election. Federal supplemental
  is 22% on the first $1M then 37% MANDATORY above → true-up gap is modest;
  the real risk is the December-settlement / spring-lockup timing trap.
- IF QSBS §1202 possible → verify before any transfer (companies past the
  gross-asset test don't qualify — most late-stage private companies).

### Insurance & protection
- IF liquid net worth ≥ ~$1M and no umbrella → immediate gap; coverage ≥
  net worth (post-liquidity $5–10M+ via a HNW carrier and independent
  broker — Chubb/PURE/Cincinnati/AIG).
- IF term life ends before youngest child's independence → coverage cliff.
- IF net worth alone funds all survivor goals → household may be OVER-
  insured; but IF the wealth is CONTINGENT (unvested equity that dies with
  the earner) → term life sized to the contingency is the real need.
- IF disability is group-LTD-only → 60% employer-paid = ~36% after tax,
  monthly caps, maybe not own-occ → individual own-occ policy is the
  biggest uninsured risk for a high-W-2 30-something.
- IF household employs domestic staff → workers' comp / DBL/PFL /
  payroll compliance exposure (many states/cities mandate coverage at hour
  thresholds).

### Estate (state law drives this — check the household's state)
- IF minor children and no guardian in a will → highest-priority gap.
- IF any life event since docs signed (birth, wealth step-change) →
  documents presumptively stale.
- IF beneficiary designations unaudited since the last life event → audit;
  they override the will.
- IF a trust exists but assets aren't titled to it → unfunded shell.
- IF minor children would inherit outright / at 18–21 → structure in
  discretionary trusts (staged or lifetime), separate guardian from trustee.
- [state:NY] IF the NY taxable estate approaches 105% of the exclusion
  (~$7.35M in 2026) → the CLIFF: crossing 105% taxes the ENTIRE estate from
  dollar one; top rate 16%. NY has NO portability → credit-shelter /
  Clayton-QTIP language and a "Santa clause" charitable formula. Other
  states have their own exemptions and cliffs — look up the household's.
- [state:NY] IF wealth is well above the state exclusion → lifetime gifting
  is the lever: no NY gift tax, and gifts made > 3 years before death
  (clawback extended through 2031) escape NY's 16% permanently. Federal
  exemption is $15M/person, permanent under OBBBA — the "use it before
  sunset" panic is dead; the reason to plan is the state tax and any
  pre-liquidity valuation freeze.
- IF a 529 lump gift is desired → 5-year superfunding election (~$95K per
  donor per beneficiary in 2026); it's an estate tool, not an income-tax
  accelerator. UTMA: avoid at this wealth (outright at 21, kiddie tax).

### Employer benefits (open enrollment, every fall)
- Compare plans; HSA/FSA/DCFSA elections (DCFSA limit $7,500 in 2026);
  ESPP; supplemental life/LTD buy-ups. RESPECT stated plan preferences —
  a client who likes their PPO keeps it; don't re-pitch the HDHP.

### Behavioral (the advisor watching the client)
- IF client contacts more / checks more during volatility → risk-
  composure event; respond with the pre-agreed script, not a portfolio
  change.
- IF a decision is being made mid-drawdown or mid-euphoria → cooling-off;
  the IPS pre-commits to no allocation changes inside a volatility window.
- IF client frames a question as return-maximization → reframe to the
  utility/regret question ("what happens to the kids' security if it
  halves"). Loss-framing is speaking a vigilant client's objective.
- IF net worth just crossed a major threshold (the IPO) → sudden-wealth
  syndrome: paralysis, guilt, solicitation targets; deliberately slow the
  pace of irreversible decisions.
- IF client can't name "enough" → the plan has no anchor; do the
  enough/freedom-number exercise before allocation work.

## Part 2 — The service calendar (what to raise, when)

Monthly review covers: cash-flow reconciliation, concentration %,
withholding-gap accumulation, drift vs. IPS, life-event check, and any
NEW fact walked against Part 1. Beyond that:

- **Jan** — set the year's automations; new limits; W-4/withholding reset
  (esp. vs. the RSU calendar); Q4 estimate due Jan 15; net-worth statement.
- **Feb** — tax docs; verify 1099-B cost basis on equity comp (routinely
  misreported); prior-year IRA/HSA top-ups (deadline Apr 15).
- **Mar** — Q1 drift check; annual credit-report pull + freeze check.
- **Apr** — filing; Q1 estimate; spring review: projections, cash flow.
- **May** — line-by-line review of the FILED return against Part 1's tax
  rules; reconcile Sched B/D to accounts; log carryforwards.
- **Jun** — Q2 estimate; insurance review in EVEN years (umbrella limits,
  disability adequacy, in-force illustrations).
- **Jul** — estate review in ODD years (beneficiary audit, doc currency,
  trust funding, guardians).
- **Aug** — 529/education check; idle-cash + FDIC-dispersion sweep.
- **Sep** — Q3 estimate; year-end tax projection begins; open-enrollment
  prep.
- **Oct** — fall review: taxes + estate (odd) / insurance (even); enrollment
  decisions; Roth-conversion sizing while brackets are known.
- **Nov** — loss/gain harvesting; DAF funding with appreciated stock;
  annual-exclusion gifts; equity-comp year-end withholding true-up.
- **Dec** — execute every Dec-31 deadline: harvesting, conversions,
  charitable, gifts, FSA spend-down, backdoor Roth, 401(k) max check.

Quarterly estimated-tax dates: Apr 15, Jun 15, Sep 15, Jan 15 (federal +
state; some cities/districts add their own — [state:NY] NYC + MCTMT).

## Part 3 — Life-event playbooks (fire the whole list on the trigger)

**New child** — health enrollment within the 30–60-day window; guardian
+ trust provisions; contingent beneficiaries via trust (never outright);
re-run life/disability need; 529 (the household's state plan if it has a
deduction, else any low-cost plan); DCFSA; childcare as a recurring line;
nanny → payroll compliance.

**IPO / liquidity (the defining event)** — the most consequential
after-tax decisions happen 12–24 months BEFORE liquidity. T-24 to T-12:
inventory grants; ISO/AMT model + settlement-year plan; estate freeze
while value is low; assemble CPA + estate attorney. T-6: written hold
thesis with exit rules; drawdown test; open the DAF; pre-set the target
post-event allocation. Lockup: 10b5-1; no reacting to price; estimated
taxes. Post-lockup, multi-year: staged diversification, harvest losses to
offset, appreciated shares to DAF, umbrella to $5–10M+, estate docs
upgraded, state-estate-tax planning becomes urgent, fund the security
bucket FIRST. Have written down in advance what the money is FOR.

**Sudden wealth (generalized)** — freeze irreversible decisions 6–12
months; park across FDIC/SIPC limits or in Treasuries; expect
solicitations; build the decision filter.

**Job change** — old 401(k) disposition; unvested equity forfeited (ISOs
must be exercised within 3 months of termination); benefits gap; W-4.

**Death of a spouse** — 10+ certified death certificates; SSA; no rushed
decisions; retitling; spousal IRA rollover vs inherited; federal
portability election (Form 706 — file even if no tax); [state:NY] NY has
NO portability, and other states vary — check.

**Moving states (leaving a high-tax state)** — burden of proof is on the
taxpayer; undocumented days count against you; defeat domicile AND
statutory residency (typically 183 days + an abode); execute for real
12–24 months before liquidity. Many states source deferred comp to
workdays already earned there — check the origin state's rules.

## Part 4 — Team, fees, and what to refuse

The right team for a high-net-worth household: a CPA who does proactive
PROJECTION (not just filing); an estate attorney competent in the
household's state; an independent P&C broker with HNW carriers; a
life/disability broker for individual own-occ coverage; household payroll
if there's staff. NOT a family office (that's a $100M+ structure;
multi-family offices want $30–100M).

**The fee arithmetic to state bluntly** (worked at $25M as the example):
1% AUM = $250,000/year, every year, rising with the market, for advice whose complexity doesn't
scale with the balance — and an AUM advisor is paid to oppose anything
that shrinks the pot (mortgage payoff, gifting, real estate). Even the
discounted HNW rate (~66 bps) is $165K/yr. Flat-fee comprehensive planning
runs ~$10–50K/yr for complex HNW. Directories: NAPFA, XY Planning
Network, Advice-Only Network. This system IS the coordinator layer; it
escalates to the human CPA / attorney / broker for judgment and
signatures.

**Refuse on the client's behalf:** 1% AUM at eight figures; commissioned
insurance dressed as planning (whole life / annuities pitched to a young
family that needs term); brokerage "advisors" without a fiduciary duty;
anything with an exit penalty. The test to hand the client: *"How are
you paid, in dollars, per year — and what would you tell me NOT to do
that costs YOU money?"*

## Part 5 — Behavioral craft (diagnose the client, then advise to their type)

First diagnose the client's money script (Klontz): AVOIDANCE (ignores
money), WORSHIP (more will fix everything), STATUS (net worth = self-worth),
or VIGILANCE (frugal, secretive, compulsive saver). Record it in the
household's THESIS.md — it inverts what "good advice" means:
- A **vigilant** client is often wealthy but MORE anxious; their failure
  mode is UNDER-LIVING the money, not blowing it. The task inverts: guard
  against excess fear and paralysis; permission to spend/enjoy is a
  legitimate deliverable; a bigger-than-textbook cash buffer that buys
  sleep is a correct recommendation, not a compromise.
- A **status/worship** client needs guardrails, automation that saves
  before they see it, and framing around what the money is FOR.
- Ask the family money history — one open question ("what did you learn
  about money growing up?") surfaces more than a questionnaire, and an
  inherited scarcity script deserves respect, not correction.

- **Optimize utility, not return.** The largest thing an advisor does
  (Vanguard's Advisor's Alpha: ~1.5%/yr of the ~3% total) is behavioral —
  preventing the one self-inflicted wound in the year that matters. Say so.
- **Risk required is LOW at this wealth.** The blunt, calming truth to lead
  with: "you don't need this portfolio to be aggressive; the number is
  won; the game now is not losing it." That reframe IS the intervention.
- **Two-dimensional risk, made explicit:** capacity is enormous, but we
  build to TOLERANCE, on purpose. Being told "we could afford far more
  risk than we're taking" is deeply calming to this personality.
- **Bucketing as engineered mental accounting** — mathematically identical
  to a total-return portfolio; the value is entirely behavioral. Build a
  labeled security bucket (N years of core living + all near-term
  outlays) ring-fenced from the growth bucket the client "will not touch
  for 10+ years." Volatility then happens to money the client doesn't need.
- **Pre-commitment devices (Ulysses contracts):** decide calm, bind the
  future self — the 10b5-1 plan, the IPS's no-change-during-drawdown
  clause, the written hold thesis with pre-set exit triggers, the
  mechanical selling rule. Any future move EXECUTES a plan; it does not
  MAKE a decision.
- **Automate the flows** so the plan runs without decisions; decisions are
  what generate anxiety. (Clients often quietly build such
  machines themselves — a forced-savings split, a labeled bucket. LOOK for
  them before prescribing; respect and extend, don't dismantle. But watch
  for the 'boomerang': money auto-swept out that the client then drags back
  to pay bills — that's a plumbing bug, not discipline.)
- **Frame in the client's objective function** — for a vigilant client
  never pitch upside; frame as security/regret and the drawdown test.
- **Under-promise, show margin.** Vigilant clients trust conservative
  assumptions and distrust rosy ones.
- **Facts first, then opinions.** Load the COMPLETE picture (statements,
  paystubs, plan documents, the return) before recommending anything.
  Half of a generic high-earner playbook does not apply to a client who
  has quietly built better systems than the playbook prescribes. Every
  wrong-because-uninformed recommendation costs credibility that the
  right ones need.
