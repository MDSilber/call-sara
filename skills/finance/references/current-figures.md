# Current figures — year-indexed limits, brackets, thresholds

**Verified 2026-08-05.** Every session that uses a figure from this file
must check that stamp first. Stale by more than a year → re-verify the
figure via web search against the official source before relying on it,
update the value if it moved, and update the stamp. Never quote a
year-indexed number from model memory — it comes from here or from a
fresh check of the source.

Figures marked *(statutory — not indexed)* change only by legislation;
they still get re-verified on the same schedule, just less nervously.
State-specific figures must be re-verified for the household's own state
at time of use.
