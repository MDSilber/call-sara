# Out of scope — decided, on purpose

One file per rejected concept. Read the file before pitching the idea —
in an issue, a PR, or a session. If the reasoning has genuinely aged out,
say so against what's written here; "but other apps have it" isn't that.

Each entry is three parts: the decision, the reasoning, and the escape
hatch — because almost nothing here is "impossible," just not what this
product is.
